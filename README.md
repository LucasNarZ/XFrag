# XFrag

## Descrição

O XFrag é uma plataforma desenvolvida para auxiliar médicos na identificação de possíveis características relacionadas à Síndrome do X Frágil.

O sistema funciona através de um checklist clínico, onde cada característica possui um peso específico. Ao final, o sistema realiza uma pontuação que pode indicar uma possível portabilidade da síndrome.

O principal objetivo do projeto é ajudar profissionais da saúde a realizarem uma triagem inicial de forma mais acessível, reduzindo a necessidade de repetição frequente de exames laboratoriais, que possuem alto custo.

# Funcionalidades

- Checklist clínico de pacientes
- Sistema de pontuação com pesos
- Login para médicos
- Auxílio na análise de possíveis características da Síndrome do X Frágil
- Armazenamento de dados em banco MySQL

# Instalação e Execução

Atualmente, o sistema funciona apenas em ambiente local, sendo necessário realizar sua configuração na máquina do usuário para execução. A funcionalidade de compartilhamento e hospedagem online ainda está em fase de implementação. Como proposta futura, pretende-se disponibilizar o sistema em servidores web para facilitar o acesso de profissionais da saúde sem necessidade de configuração técnica.
